# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting feature if it is enabled for this repository.
Otherwise contact the repository owner privately through their GitHub profile.

Include a description of the issue, affected files or versions, reproduction
steps, and the potential impact. Please do not attach real literature exports,
personal data, or credentials.

## Data protection

This application is designed for local processing. Do not deploy it publicly
without authentication, HTTPS, upload limits, access controls, and an explicit
data-retention policy. Never commit API keys or `.env` files.
