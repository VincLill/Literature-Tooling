# Code of Conduct

We want this project to be welcoming and useful to everyone.

## Expected behavior

- Be respectful and constructive.
- Focus on the problem, not the person.
- Share reproducible examples without private data.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, and publishing private
information are not tolerated.

Report serious issues privately to the repository owner rather than opening a
public issue.
